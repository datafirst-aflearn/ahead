2021 Early Grade Activity (DEGRA)

From 2019 to 2024, the Djibouti Early Grade Reading Activity (DEGRA), a USAID-funded project implemented by FHI 360, aimed to improve reading outcomes in primary schools across Djibouti for Grades 1–5 learners. Data were collected using the Early Grade Reading Assessment (EGRA) in French and Arabic in November 2020, November 2021, and April 2022. The project was nationally representative of in-school primary learners in Dijibouti.

Assessment Subtasks

The subtasks included in this assessment survey are described below.

Letter sound identification

Learners identify letters by corresponding sound within 60 seconds (LSCPM). Discontinued if no letters in the first line are correct.

Non-word reading

Learners read aloud pseudowords within 60 seconds (CWPM). Discontinued if none of the first five words are correct.

Oral reading fluency

Learners read a grade-appropriate passage within 60 seconds (CWPM). Discontinued if none of the first ~10 words are correct.

Reading comprehension

Learners answer questions on a passage; may allow look-backs. Untimed.

Listening comprehension

Learners listen to a passage and answer comprehension questions. Untimed; no discontinuation rule.
